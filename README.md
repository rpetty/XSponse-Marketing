# XSponse-Marketing

Marketing site and assets for XSponse.

## School Safety Enhancement (SSE) Grant Landing Page

`index.html` is a self-contained landing page highlighting the U.S. Department of
Education's FY 2026 School Safety Enhancement Program ($93M) and how XSponse maps to
the grant's allowable uses. No build step or dependencies — pure HTML/CSS/JS.

### Hosting with GitHub Pages
1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source = Deploy from a branch**, branch
   **main**, folder **/ (root)**, then **Save**.
4. The site publishes at `https://<your-username>.github.io/XSponse-Marketing/`
   within a minute or two.

### Notes before going live
- Replace the placeholder CTA link `xsponse.com/school-safety-grant` and the
  `grants@xsponse.com` address with live destinations.
- The lead form is a front-end demo (no backend). Wire it to your form handler
  (HubSpot, Formspree, etc.) before collecting submissions.
- Grant figures and the **July 28, 2026** deadline are summarized from the FY 2026
  SSE Application Notice and Instructions; confirm current details at ed.gov.
